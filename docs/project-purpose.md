# Project Purpose — KATANAWEB

## Qué es
Web de servicios de desarrollo para negocios locales. Dos desarrolladores ofrecen diseño y desarrollo web a medida.

## Audiencia objetivo
Negocios locales (hostelería, comercio, servicios) que necesitan presencia web pero no tienen equipo técnico propio.

## Objetivo del sitio
Generar confianza y captar clientes. El sitio es el producto comercial principal del equipo.

## Páginas actuales
- `index.html` — home y propuesta de valor principal
- `servicios.html` — catálogo de servicios ofrecidos
- `proceso.html` — cómo trabajamos
- `portfolio.html` — trabajos realizados
- `nosotros.html` — quiénes somos
- `briefing.html` — formulario de contacto inicial / briefing
- `contacto.html` — contacto directo
- `legal/aviso-legal.html`, `legal/cookies.html`, `legal/privacidad.html` — páginas legales

## Prioridades
1. Rendimiento y tiempo de carga
2. SEO on-page (posicionamiento local)
3. Claridad del mensaje y confianza
4. Mantenibilidad del código

## Fuera de scope (fase actual)
- Backend, base de datos, autenticación
- CMS o panel de administración
- Integraciones con servicios de terceros (salvo formularios básicos)
- E-commerce

## Fases del proyecto
- **Fase 1 (actual):** HTML + CSS + JS puro
- **Fase 2 (próxima):** Migración a React + Vite, sitio estático
- **Fase 3 (futura):** Añadir backend (stack por definir)
