## Stack Técnico
Fieles a nuestra filosofía de "Precisión antes que velocidad", este sitio está construido con un stack moderno, modular y eficiente, huyendo de constructores visuales (no-code) que ensucian el código:
* **React** (Framework principal para la interfaz)
* **Vite** (Entorno de desarrollo y construcción ultrarrápido)
* **JSON** (Gestión de datos y configuración)
* **HTML5 & CSS3** (Arquitectura moderna con Variables, Grid y Flexbox)

## Estructura del Proyecto
Nuestra arquitectura refleja nuestra forma de trabajar: limpia y directa.
* `/src/components/` - Componentes reutilizables de la UI (Header, Footer, etc.)
* `/src/pages/` - Vistas principales (Home, Portfolio, Servicios, Proceso, etc.)
* `/public/` - Assets estáticos.
